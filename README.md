## 🛠️ My Problem-Solving Workflow

```text
Understand the problem
        ↓
Identify constraints and edge cases
        ↓
Build a straightforward solution
        ↓
Analyze time and space complexity
        ↓
Optimize using the right data structure or pattern
        ↓
Test examples, boundaries, and tricky cases
        ↓
Review and document what I learned
```

## 🏆 Selected Problem Patterns

| Pattern | Key idea |
|---|---|
| Two pointers | Move through a sequence with coordinated indices |
| Sliding window | Maintain a useful range while scanning |
| Hashing | Trade extra space for faster lookup |
| Binary search | Reduce a sorted search space |
| Stack / monotonic stack | Track order and resolve previous/next elements |
| Tree traversal | Explore nodes using DFS or BFS |
| Heap / priority queue | Repeatedly access the smallest or largest item |
| Backtracking | Explore choices and undo them when needed |
| Dynamic programming | Reuse results of overlapping subproblems |
| Graph traversal | Explore connected states while tracking visited nodes |
